# chatlas

Проект «Telegram-бот для получения списка участников чата по истории сообщений» по дисциплине "Проектная практика" (хакатон). 1-й семестр 2-го курса МИФИ ИИКС РПО (2025-2026 уч. г).

Проект представляет собой Telegram-бота, предназначенного для получения списка участников Telegram-чата по отправляемому стандартному файлу выгрузки экспорта.

Подробные требования к проекту описаны в файле [задания](task.md).

## Документация

Подробная документация по проекту находится в файле [документации](docs/project_description.md).

## Запуск проекта

### Предварительные условия

Для запуска проекта необходимо иметь:

1. Установленные Docker и Docker Compose.
2. Java 21 или выше.
3. Maven.

### Алгоритм запуска

Для запуска проекта необходимо:

1. Запустить Docker.
2. Получить токен бота у `@BotFather`.
3. Добавить полученный токен в переменные окружения. Для этого можно выбрать один из двух вариантов (далее `REAL_TOKEN` — токен, полученный от `@BotFather`):
   1. Честно добавить токен в переменные окружения (например, прописав `export TELEGRAM_BOT_TOKEN=REAL_TOKEN` в `.bashrc`).
   2. Создать в корне репозитория `.env` файл с содержимым `TELEGRAM_BOT_TOKEN=REAL_TOKEN`.
4. Запустить проект командой `docker compose up --build` (команду необходимо запускать, находясь в корне проекта).

## Соответствие функциональным требованиям

Последовательно пройдемся по всем требованиям из задания:

- **Прием истории чата**: Бот поддерживает загрузку файлов выгрузки (экспорта) чата в формате JSON.
- **Извлечение участников**: Система корректно находит пользователей, писавших сообщения, и тех, кто был упомянут в тексте.
- **Фильтрация и дедупликация**: реализовано удаление дублей по уникальным ID и автоматическое исключение удалённых аккаунтов.
- **Гибкий формат вывода**:
    - При количестве участников < 51 бот присылает результат обычным сообщением.
    - При количестве участников >= 51 бот формирует и отправляет Excel-файл.
- **Структура Excel**: Файл содержит требуемые поля: Дата экспорта, Username, Имя и фамилия.
- **Конфиденциальность**: Бот обрабатывает данные «на лету» без сохранения файлов на сервере.
- **Надежность**: Проект покрыт Unit-тестами, проверяющими логику парсинга и анализа.
- **Контейнеризация**: Проект полностью настроен для запуска через Docker Compose.
